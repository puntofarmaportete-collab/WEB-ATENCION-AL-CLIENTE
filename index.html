☁ Inventario en Firebase

Inventario local · Firebase pendiente de conexión.

La carga de Excel se guarda primero en este navegador. Pulsa Guardar para compartirla. Traer reemplaza la copia local. Limpiar catálogo solo borra la copia local. Los casos y solicitudes no se envían a Firebase.

Activar acceso sin correo ni contraseña
  1. Firebase → Authentication → Método de acceso → Anónimo → Habilitar y guardar.
  2. Abre esta web desde GitHub Pages y pulsa Conectar dispositivo.
  3. Copia el identificador que aparece debajo. En Realtime Database → Datos, agrega un nodo devices; dentro agrega ese identificador con valor booleano true (sin comillas).
  4. En Realtime Database → Reglas, publica las reglas de abajo. Después pulsa Conectar dispositivo otra vez.
  5. Repite la autorización para cada navegador que utilizará el inventario. Borrar los datos del navegador o usar incógnito puede generar otro identificador.

Este navegador: Aún no conectado 

{
  "rules": {
    ".read": false,
    ".write": false,
    "inventory": {
      ".read": "auth != null && root.child('devices').child(auth.uid).val() === true",
      ".write": "auth != null && root.child('devices').child(auth.uid).val() === true",
      ".validate": "newData.hasChildren(['schema', 'payload', 'updatedAt']) && newData.child('schema').val() === 1 && newData.child('payload').isString() && newData.child('updatedAt').isNumber()"
    }
  }
}

Cada dispositivo autorizado puede consultar y reemplazar el inventario. Para revocarlo, elimina su identificador de devices. La autenticación anónima identifica el navegador sin pedir registro al colaborador.

Cómo usar el asistente de casos

1. Confirma la información

El análisis usa reglas limitadas; puede omitir o interpretar mal una frase. No supone edad, duración ni ausencia de riesgos.

2. Prioriza la atención

Una alerta interrumpe la búsqueda comercial. La ausencia de coincidencias automáticas no descarta una urgencia.

3. Revisión de medicamentos

Los módulos no habilitan prescripciones. Antes de proponer un medicamento se necesita una ficha específica, condición de dispensación en Ecuador y criterio del farmacéutico. Esta versión no tiene protocolos farmacéuticos aprobados.

4. Inventario del navegador

El catálogo corresponde a un archivo cargado, no a existencias en tiempo real. Confirma cantidad física, presentación, unidad de venta y precio.
